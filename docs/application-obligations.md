# Application obligations

Applications propose versioned actions, RPC services and sponsorship terms. Provider operators accept the current obligations before user execution. Actions must describe exact permitted calls and limits; sponsorship must bound gas, fees and active accounts.

The funding address and Safe infrastructure belong to that accepted application identity. Accepted policy, grant and chain authority are rechecked at financial boundaries. Changing policy does not rewrite an existing signed operation. See [runtime configuration](runtime-configuration.md) and [HTTP schemas](http-reference.md).
