# Package surface

The package exposes core authority, HTTP composition, onboarding, identity, telemetry, storage, deployment, OWS signing, wallet calls and sponsorship modules. Read the generated [TypeScript declarations](api-reference.md) and [HTTP contract](http-reference.md).

Run `npm run build` to rebuild the distribution from a clean output directory. Run `npm run check:package` to install the packed artifact into an isolated consumer and verify its supported exports and executable. npm publication is disabled in this private package.
