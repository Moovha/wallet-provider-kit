# Operator services

The provider API authenticates application clients independently of owner grants. Configure the bundled OAuth issuer or an exactly matching trusted issuer. Register provider policy operators separately from application clients.

The OWS vault stores private Safe owner signers. The private bundler sends approved UserOperations to EntryPoint; the verifying paymaster signs bounded sponsorship. RPC endpoints provide canonical state and receipt evidence. Endpoint scheduling may use multiple endpoints without changing account or spending authority.

Optional staff login controls application token administration. It is not a wallet owner identity source. Keep credential references in configuration and values in the deployment secret store.
