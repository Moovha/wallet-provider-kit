# Manage applications and policy

First register applications after deployment using `/admin/` or the protected
provider identity API. Accept identity/consent trust separately from registration.
See [provider administration](provider-installation.md).

Use application configuration endpoints to read current policy, propose changes and inspect obligations. Use a distinct provider operator identity to publish or accept revisions. Register actions, canonical RPC services and bounded sponsorship before provisioning user Safes.

Configuration availability does not establish readiness or current owner permission. Read [runtime policy](runtime-configuration.md), [application obligations](application-obligations.md) and [HTTP schemas](http-reference.md).
