# Staging acceptance

Prepare an isolated testnet deployment with wallet operations disabled and retained persistent storage. Complete [deployment acceptance](conformance.md), publish the application policy, accept services and sponsorship, fund the application gas address within explicit limits and provision its bundler/paymaster.

Establish trusted application-led identity, consent and a current owner grant. Provision one Safe per user. Submit approved zero-value atomic calls and verify batch acknowledgement, canonical inclusion and finality independently. Exercise retries, revocation, changed calldata and uncertain responses without clearing retained evidence.

For latency comparisons, use the same ten users, Safes and workload described in [execution latency](execution-latency.md). Preserve failures and report all ten outcomes. Do not infer production capacity from testnet results.
