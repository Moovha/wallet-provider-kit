# Runtime policy

Application clients propose action policy; separate provider operators publish it. Accepted actions, services and sponsorship must agree with the active revision. Publishing does not infer user consent or identity.

The provider binds each current owner to their own Safe. Contract policy can restrict target addresses, methods, argument positions and explicit user-address parameters. All calls still pass the current immutable intent, account proof and financial authority checks. Manual and automatic policy review concern publication decisions, not execution selection.

Use the [HTTP schemas](http-reference.md) for proposal, publication, obligations and credential metadata endpoints. Secret material is never returned in metadata.
